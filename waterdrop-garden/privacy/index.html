물방울 정원 개인정보처리방침

시행일: 2026년 11월 26일 · 개발자: 나늬 스튜디오 (Nanee Studio)

English version

나늬 스튜디오(이하 "스튜디오")는 모바일 퍼즐 게임 "물방울 정원"(이하 "게임")을 만들어 배포합니다. 이 문서는 게임이 이용자의 정보를 어떻게 다루는지 설명합니다.

1. 요약

  • 회원 가입이나 로그인이 없습니다.
  • 게임은 이름, 이메일, 전화번호, 연락처, 사진, 위치, 광고 ID를 수집하지 않습니다.
  • 게임에는 광고, 이용 분석, 인앱 결제가 없습니다.
  • 게임 진행 상황과 플레이 기록은 이용자의 기기 안에만 저장되고, 스튜디오의 서버로 보내지 않습니다.

2. 기기에 저장되는 정보

다음 정보는 이용자의 기기 안에만 저장됩니다. 스튜디오는 이 정보를 볼 수 없습니다.

  • 게임 진행 상황: 깬 단계, 별, 연승, 코인, 목숨, 정원 꾸미기 상태
  • 최고 기록과 명장면 리플레이: 조준 각도와 발사 시점 같은 게임 입력만 담깁니다
  • 설정: 배경음과 효과음 음량, 진동 켜기·끄기
  • 테스트용 플레이 기록: 단계별 시도, 성공, 실패 횟수와 게임 오류 메시지

기기의 백업 기능을 켜 두었다면, 기기 제조사나 운영체제의 백업 서비스가 앱 데이터를 함께 보관할 수 있습니다. 이 경우 해당 서비스의 방침이 적용됩니다.

앱을 삭제하면 기기에 저장된 게임 정보도 함께 지워집니다.

3. 이용자가 직접 보내는 정보

이용자가 "자랑하기", "공유", "테스트 기록 보내기"를 누르면 기기의 공유 화면이 열립니다. 이용자가 고른 앱(메신저 등)으로 리플레이 코드나 플레이 기록 글이 전달됩니다. 무엇을 누구에게 보낼지는 이용자가 정하며, 스튜디오는 이 내용을 받지 않습니다. 단, 이용자가 스튜디오에 직접 보낸 경우에는 받은 내용을 게임 개선에만 쓰고, 목적을 이룬 뒤 지웁니다.

리플레이 코드에는 단계 번호와 게임 입력만 들어 있고, 이용자를 알아볼 수 있는 정보는 들어 있지 않습니다.

4. 클립보드

게임 화면으로 돌아올 때, 친구가 보낸 리플레이 코드("WG"로 시작하는 글)가 클립보드에 복사되어 있는지 기기 안에서 확인합니다. 코드가 있으면 그 리플레이를 볼지 묻습니다. 클립보드 내용은 저장하거나 기기 밖으로 보내지 않습니다. 같은 코드를 다시 묻지 않도록, 마지막으로 확인한 리플레이 코드 하나만 기기 안에 기억합니다.

5. 기기 권한

  • 진동: 물방울이 잎과 꽃에 닿을 때 손맛을 주는 데만 씁니다. 설정에서 끌 수 있습니다.
  • 리플레이 영상 저장: 이용자가 영상 공유를 누르면 영상을 기기의 동영상 폴더(Movies/물방울정원)에 저장하고 공유 화면을 엽니다.

6. 리플레이 링크 페이지

리플레이 링크(https://naneestudio.github.io/waterdrop-garden/r/)는 GitHub Pages에서 제공됩니다. 리플레이 코드는 주소의 "#" 뒤에 있어서 웹 서버로 전송되지 않습니다. 페이지를 여는 과정에서 GitHub가 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.

7. 아동

게임은 어린이를 포함한 누구의 개인정보도 수집하지 않습니다.

8. 방침의 변경

광고, 이용 분석, 결제처럼 정보를 다루는 기능을 추가하면 이 문서를 먼저 고치고, 시행일을 바꿔 이 주소에 알립니다.

Waterdrop Garden Privacy Policy

Effective date: November 26, 2026 · Developer: Nanee Studio

한국어

Nanee Studio ("we") makes and distributes the mobile puzzle game "Waterdrop Garden" (the "Game"). This policy explains how the Game handles your information.

1. Summary

  • There is no sign-up or login.
  • The Game does not collect your name, email, phone number, contacts, photos, location, or advertising ID.
  • The Game has no ads, no analytics, and no in-app purchases.
  • Your progress and play records are stored only on your device and are never sent to our servers.

2. Information stored on your device

The following stays on your device only. We cannot see it.

  • Game progress: cleared stages, stars, win streak, coins, lives, garden decorations
  • Best records and highlight replays: game inputs only, such as aim angles and shot timing
  • Settings: music and sound volume, vibration on/off
  • Test play records: attempts, clears, and failures per stage, and game error messages

If device backup is turned on, your device maker's or operating system's backup service may keep app data. Their policies apply in that case.

Uninstalling the Game deletes the information stored on your device.

3. Information you choose to send

When you tap "Share", "Show off", or "Send test record", your device's share screen opens and the replay code or play record text goes to the app you choose (such as a messenger). You decide what to send and to whom; we do not receive it. If you send it to us directly, we use it only to improve the Game and delete it afterward.

A replay code contains only a stage number and game inputs. It contains nothing that identifies you.

4. Clipboard

When you return to the Game, it checks on your device whether a friend's replay code (text starting with "WG") is in your clipboard, and if so asks whether you want to watch it. Clipboard content is not stored or sent off your device. To avoid asking twice, the Game remembers only the last replay code it checked, on your device.

5. Device permissions

  • Vibration: used only for haptic feedback during play. You can turn it off in Settings.
  • Saving replay videos: when you tap video share, the video is saved to your device's Movies/물방울정원 folder and the share screen opens.

6. Replay link page

The replay link page (https://naneestudio.github.io/waterdrop-garden/r/) is hosted on GitHub Pages. The replay code sits after "#" in the address, so it is not sent to the web server. GitHub may process access logs (such as IP addresses) when the page is opened, under the GitHub Privacy Statement.

7. Children

The Game does not collect personal information from anyone, including children.

8. Changes

If we add features that handle information, such as ads, analytics, or payments, we will update this policy first and post it at this address with a new effective date.
